02

Canonical Lesson Object

All intelligence, editing, and refinement operate on the same structured object. This prevents fragmentation across product, intelligence, and analytics layers.

lesson_object.schema 
interface Lesson {
  metadata: {
    id: string;
    title: string;
    created_at: timestamp;
    version: number;
  };

  constraints: ConstraintSet;    // 8 high-level inputs

  sections: LessonSection[];   // 8 structured components

  confidence_score: number;  // 0.0 – 1.0 from evaluator
}

06

Iterative Confidence Refinement

An internal multi-agent evaluation loop that increases lesson confidence without requiring educator intervention. Click each step to explore.

📝
Draft Generator
Creates the initial lesson draft based on constraint inputs and learning objectives. Produces a complete structured lesson object with all 8 sections populated.
🔍
Confidence Evaluator
Evaluates the draft across six dimensions: time realism, material feasibility, setup clarity, engagement arc, energy pacing, and backup inclusion. Outputs a confidence score from 0.0 to 1.0.
💬
Structured Critique
Generates specific, actionable feedback on areas where the lesson falls short. Identifies gaps in engagement flow, timing, or material alignment.
🔧
Refinement Agent
Applies targeted improvements based on the structured critique. Refines specific sections while preserving overall lesson coherence.
✅
Final Lesson
A high-confidence, delivery-ready lesson that has been evaluated, critiqued, and refined — all before the educator sees it.

07

Engineering Principle

Structured Objects, Not Free Text

All product intelligence must operate on structured lesson objects, not free-text outputs. This is the foundational engineering principle that enables every capability in this schema.
